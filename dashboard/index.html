How to Run & Save Benchmark Sweeps

The benchmark runner iterates over the (r, ε, α) grid, trains the simulated hospital clients using Flower and PyTorch MPS/CPU, and aggregates results.

1. Standard 2-Round Fast Sweep (~30 min):

.venv/bin/python sweep.py --rounds 2

2. Full 5-Round Publication Sweep (Background / Detached):

nohup .venv/bin/python sweep.py > results/sweep_run.log 2>&1 &

3. Where Results Are Saved:

  • results/sweep_results.csv: Raw per-round metrics.
  • results/sweep_summary.json: Run runtime, grid, hardware timestamp.
  • results/history/: Timestamped archive snapshots.
